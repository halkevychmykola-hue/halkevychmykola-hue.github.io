NQ strategy explorer

Every strategy in the project followed one path: an idea with a named mechanism → a market simulator where that mechanism can be switched off → a frozen run on real Nasdaq-100 futures (NQ) data → selection by rules written in advance. Here you can open any of the 60 strategies, see how it did before and after 2017, and build a portfolio.

Monthly results 2011–2025, in % of one contract's value, summed without compounding. 2011–2016 (shaded) is where thresholds were set; 2017–2025 is the out-of-sample test. Costs are included. Raw market data is not published, only aggregated results.

Combine strategies

Pick strategies or start from a preset. "Equal risk" scales each strategy by its 2011–16 volatility, so no single one dominates, then scales the whole portfolio to the same volatility as holding one long NQ contract, so the yearly % can be compared with long NQ directly. "One contract each" simply adds the positions up, so the % grows with the number of strategies.
